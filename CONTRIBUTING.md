# Contributing

Use feature branches and focused Conventional Commits. Open a PR to main with the behavior changed and real verification results. Keep source material and runtime secrets out of Git. Run the README checks before pushing; use the existing localization resources for every UI change. Never edit generated API clients manually. Version contract changes explicitly when that contract is introduced in Phase 2.

Azure provisioning and live supplier delivery remain gated. No license has been selected; contact the owner before redistribution.
