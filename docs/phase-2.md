# Phase 2 delivery

The API repository now contains the 0.2.0-draft generated OpenAPI contract, a generator and structural validator. It covers 32 planned operations and 30 schemas: authentication/CSRF, roles and countries, CRUD, dashboard, logs, eCommerce deductions, supplier requests and health. This is a planned contract, not live routes in Swagger.

EF Core 10/SQLite has an initial migration for role/country/user/warehouse/item/session/deduction/supplier-outbox data. Role and country lookups are seeded by migration. Startup migrates and idempotently seeds one hashed first administrator; production requires an explicit bootstrap password. Schema indexes/checks enforce active normalized uniqueness, positive quantity, bounded prices, valid role/country/warehouse references and caller-scoped deduction keys. Soft deletion retains history. Application services and API endpoints will apply authorization, conditional updates, deletion rules and transactions in Phases 3/4/4A.

Local verification on 17 October 2026: locked restore and local dotnet-ef tool restore passed; Release build had zero warnings/errors; `dotnet format --verify-no-changes` passed; 18 integration tests passed on real SQLite, including the actual migration, a second initializer run, constraints, and first-production-start failure without a password. The unit-test project remains empty until application behavior exists. Contract generation and validation passed for 32 operations/30 schemas. CI runs these on each PR. The web repository pins the matching draft snapshot and generates types. See the PR checks for hosted results.
