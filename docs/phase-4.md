# Phase 4 assessment features

The versioned API now serves countries, warehouse and item CRUD, roles and user CRUD/password reset, warehouse dashboard totals, highest/lowest quantity lists, and an Admin-only event-log viewer. Inventory writes require Admin or Management; Auditor is read-only. User management and log routes require Admin. All writes use the draft contract's validation, 10-row page cap and `If-Match` ETags. Item names remain globally unique, quantities start at one, monetary values are exact two-decimal strings, and nonempty warehouses cannot be deleted. Account role/password/active/deleted changes invalidate existing tokens through the Phase 3 security-version trigger.

Serilog writes structured request events to ignored runtime JSON files with daily/1 MiB rolling and 14 retained files. The admin viewer supports pagination, level, date and message search. Request bodies, cookies and authorization headers are not logged. Production operators must keep the runtime directory private and persistent; a central log store is outside this assessment phase.

Local verification on 17 October 2026: locked restore, draft contract generation/validation, Release build without warnings, formatting and 35 integration tests passed. A live HTTPS Vite-proxy smoke test logged in, read five countries, created a temporary warehouse and item, checked dashboard quantity 3 and Admin logs, then deleted both records. Hosted CI evidence is attached to the Phase 4 PR. Browser print view and full-data loading are implemented in the web repository; browser print-preview acceptance is scheduled for Phase 5. eCommerce deductions and supplier-order outbox/delivery remain Phase 4A.
